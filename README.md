# cpp-language

A structured repository covering C++ fundamentals, core concepts, notes, and practical coding challenges.

## 📚 Repository Structure

- **`01_basics/`**: Introduction to C++, language history, features, compilation workflow, and interview Q&A.
- **`02_varconst/`**: Variables, data constants, and basic syntax.
- **`03_primitives/`**: Primitive data types, type casting, type modifiers, strings, user input, and practical challenges.
- **`04_operators/`**: Arithmetic, relational, logical, bitwise operators, and problem challenges.
- **`05_conditionals/`**: Decision-making statements (`if`, `else if`, `switch-case`) and challenges.
- **`06_loops/`**: Loop constructs (`for`, `while`, `do-while`) and iteration problems.

## 🚀 Getting Started

Compile and run any C++ file using `g++` or `clang++`:

```bash
# Example: Compile and run challenge1.cpp
g++ -std=c++17 03_primitives/challenge1.cpp -o 03_primitives/challenge1
./03_primitives/challenge1
```

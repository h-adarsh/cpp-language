# C++ Data Types

## 1. Primitive (Built-in)
Come with the language. Store simple values directly in memory.

| Type | Stores | Typical size |
|---|---|---|
| `int` | whole numbers | 4 bytes |
| `float` | decimal numbers | 4 bytes (32-bit, ~7 digits precision) |
| `double` | decimal numbers | 8 bytes (64-bit, ~15 digits precision) |
| `char` | single character | 1 byte |
| `bool` | `true` / `false` | 1 byte |
| `void` | no value | - |

- Sizes depend on the system. Check with `sizeof(type)`.
- `double` is more precise than `float`. Use `double` by default.
- `void` is not a type you can store values in. You cannot write `void x;`. It is used for:
  - functions that return nothing
  - `void*` (a pointer to any type)
- Size modifiers: `short`, `long`, `long long`, `unsigned`, `signed`. Example: `unsigned int`, `long long`.

## 2. Derived
Built on top of primitive types.

- **Array**: collection of elements of the **same** type. Example: `int marks[5];`
- **Function**: block of code with a return type and parameters.
- **Pointer**: stores the **memory address** of another variable. Example: `int* p = &x;`
- **Reference**: another **name (alias)** for an existing variable. Example: `int& r = x;`

## 3. User-Defined
Types you create yourself.

- **struct**: groups different types together. Members are `public` by default.
- **class**: same idea as struct, plus OOP features. Members are `private` by default.
- **enum**: a set of named integer constants. Example: `enum Color { RED, GREEN, BLUE };`
- **union**: all members **share the same memory**. Size = largest member. Only one member is valid at a time.

## Common Mistakes
- It is `bool`, not `boolean`. (`boolean` is Java.)
- `typedef` is **not a data type**. It only gives a **new name (alias)** to an existing type. Example: `typedef unsigned int uint;`. Modern C++ uses `using uint = unsigned int;`.
- `string` is **not primitive**. It is a class from the standard library (`std::string`, needs `#include <string>`).

## Interview Quick Hits
- **float vs double?** `double` has twice the size and about double the precision.
- **struct vs class?** Only the default access differs: `public` in struct, `private` in class.
- **Pointer vs reference?** A pointer can be null and can be changed to point elsewhere. A reference must be set when created and cannot be re-pointed.

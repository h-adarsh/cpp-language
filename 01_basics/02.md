# C++ Hello World (Short Notes)

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello World from Adarsh" << endl;
    return 0;
}
```

## Anatomy
- `#include <iostream>`
  - Preprocessor directive. Copies the header file into your code before compiling.
  - Gives `cout`, `cin`, `endl`.
  - `<>` = standard headers, `""` = your own files.
- `using namespace std;`
  - Namespace = named scope that avoids name clashes.
  - `std` holds the standard library. Without this line, write `std::cout`.
  - Avoid in header files and big projects.
- `int main()`
  - Entry point. It is a function, not a method.
  - Returns an exit status to the OS.
- `<<` = insertion operator (out, used with `cout`)
- `>>` = extraction operator (in, used with `cin`)
- `endl` = new line + flush. `'\n'` = new line only, faster.
- `return 0;` = success. Optional in `main`.

## Compile and Run
```
g++ hello.cpp -o hello
./hello
```
Stages: **Preprocess -> Compile -> Assemble -> Link**

## Interview Q&A
- **`endl` vs `'\n'`?** `endl` also flushes the buffer, so it is slower.
- **Why avoid `using namespace std;`?** Name clashes in large projects and headers.
- **What does `main` return?** An `int` exit status. `0` = success.
- **`#include <x>` vs `#include "x"`?** Angle brackets search standard paths. Quotes search your project folder first.

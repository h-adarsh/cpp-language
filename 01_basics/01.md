# C++ Intro (Short Notes)

## History
- **Creator:** Bjarne Stroustrup, Bell Labs
- **Timeline:** started 1979 ("C with Classes"), named C++ in 1983, first commercial release 1985
- **Standards:** C++98, 03, **11 (major change)**, 14, 17, 20, 23

## Features
- Compiled
- Statically typed (types checked at compile time)
- Multi-paradigm (procedural, OOP, generic, functional), not only OOP
- Fast (native machine code, no VM, no garbage collector)
- Pointers and manual memory control (powerful but risky)

## Platform
- **Not platform independent.**
- Source code is portable. The executable is platform-specific.
- Recompile for each OS.

## Compiled Language
- The compiler (g++, clang, MSVC) translates the whole program to machine code *before* running.
- The compiler is needed only to build, not to run.

## Why C++
- Performance: games, browsers, databases, trading, embedded
- Teaches how memory and systems work
- STL is good for DSA

## Interview Q&A
- **Is C++ platform independent?** No. Source is portable, executable is not.
- **Is C++ purely OOP?** No. It is multi-paradigm.
- **What does statically typed mean?** Type is fixed and checked at compile time.
- **Compiled vs interpreted?** Compiled: translate everything first, then run. Interpreted: translate and run line by line.
